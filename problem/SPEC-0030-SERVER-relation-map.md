# SPEC-0030 — 관계 지도: 여러 명과의 겹침을 보려면 관계가 저장되어야 합니다

- 대상: 신규 오퍼레이션 4개(아래 §요청)
- 확인 환경: `http://localhost:8888/graphql` 2026-08-22
- 상태: **요청 중**

## 왜 필요한가

지금 공유 링크는 **단방향 스냅샷**이다.

```
나 ──[링크 발급]──▶ 상대가 링크 열람
                      │
                      └─ 상대만 겹침을 본다. 나는 아무것도 모른다.
```

링크를 뿌린 사람은 **누가 열었는지도, 무엇이 겹쳤는지도 모른다.** 열람 사실이
돌아오지 않기 때문이다. 그래서 "여러 명과 겹치는 곳을 본다"가 원리적으로
불가능하다 — 링크는 관계를 만들지 않고 보여주고 끝난다.

**관계가 저장되어야 한다.** 이것이 이 요청의 전부다.

## 정해진 규칙 (사용자 결정, 2026-08-22)

| 항목 | 결정 | 이유 |
|---|---|---|
| 누가 등록하나 | **공유받은 사람** | 자기 기록을 자기 의사로 내놓는 것이라 링크 주인의 허락이 필요 없다 |
| 링크 주인의 권한 | **삭제만** | 넣을 권한은 들어온 사람에게, 뺄 권한은 목록 주인에게 |
| 누가 보나 | **양쪽 다** | 단, 앱 설치는 필요하다 |
| 겹침 수 기준 | **볼 때마다 재계산** | 서로 더 다니면 겹침이 늘어야 자연스럽고, 그것이 다시 열어볼 이유가 된다 |
| 삭제 범위 | **각자 자기 목록만** | 내 화면에서 누굴 안 볼지는 내가 정한다. 상대 목록까지 지우면 남의 화면을 건드리는 것이다 |

**등록 시점 스냅샷으로 굳히지 않는다.** 굳히면 여행을 더 다녀도 숫자가 그대로라
기능이 한 번 쓰고 버려진다.

**삭제는 대칭이 아니다.** 내가 상대를 지워도 상대 목록의 나는 남는다. 서로를
지울 수 있게 하면 상대가 내 화면을 바꿀 수 있게 된다.

## 흐름

```
나 ──[링크 공유]──▶ 상대가 링크 열람
                      │
                      ├─ 비로그인 → 겹침 못 봄 → 앱 설치 유도
                      │
                      └─ 로그인 → 겹침 보임 → [등록]
                                                │
                                    양쪽 관계 목록에 서로 추가
                                    각자 자기 목록에서만 삭제 가능
```

## 요청

### 1. 관계 등록

공유 토큰으로 등록한다. 등록하는 쪽이 로그인 상태여야 한다.

- 자기 자신의 링크로는 등록되지 않아야 한다
- 이미 등록된 상대면 **멱등**이어야 한다(중복 생성 금지)
- 폐기·차단된 토큰이면 거절

### 2. 관계 삭제

**내 목록에서만** 지운다. 상대 목록은 그대로다.

### 3. 내 관계 목록 조회

한 사람마다 필요한 것:

- 상대 식별자, 닉네임
- **겹친 칸 수** — 조회 시점에 재계산한 값
- **겹친 칸 id 목록** — 화면에서 지도에 표시한다
- 상대의 총 방문 칸 수 (겹침 비율을 보여주려면 필요하다)

목록이 길어질 수 있으므로 페이지네이션이 있으면 좋다.

### 4. 겹친 칸의 이름

지금 `sharedMap`은 **칸 id만** 준다. "6곳이 겹쳐요"라고만 쓸 수 있고 어디인지
말할 수 없다. 겹친 칸의 이름(예: 강원·부산)을 함께 주면 화면에서 나열할 수 있다.

`mapCells`로 이름을 얻을 수는 있지만, 비로그인 열람자는 그 목록이 없다.

## 클라이언트가 이미 갖춘 것

- 겹치는 칸을 **테두리로** 표시한다(색은 시도별로 이미 쓰고 있어 채널이 없다)
- `sharedMap`의 `overlappingCellIds`에서 **null과 빈 배열을 구분**한다 —
  null은 비교 불가(비로그인), 빈 배열은 비교했으나 겹침 없음
- 공유 링크를 조립하지 않고 서버가 준 `shareUrl`을 그대로 쓴다
