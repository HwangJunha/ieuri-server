# 칸 대표 이미지 375장 중 17장이 다른 곳의 사진이었다

사용자가 "성산일출봉에 음식 사진이 나온다"고 제보했다. 375장을 전부 내려받아 눈으로
확인한 결과 17장이 어긋나 있었다.

## 원인 — planner의 이름 검색

`ieuri-planner/out/landmarks-161-with-images.json`이 TourAPI를 **장소 이름으로 검색해
첫 결과의 이미지**를 가져왔다. 그 결과가 엉뚱한 상호인 경우가 있었고, 원본 JSON의
`tour.title`에 그 상호가 그대로 남아 있다.

| 의도한 장소 | TourAPI가 실제로 준 것 |
|---|---|
| 성산일출봉 | 성산흑돼지두루치기 성산일출봉점 |
| 불국사 | 불국사밀면 |
| 장릉(영월) | 장릉황제손짜장 |
| 주남저수지 | 주남저수지돌짜장 |
| 동피랑 벽화마을 | 동피랑전복마을 |
| 창덕궁 | 이새 창덕궁점 |
| 서오릉 | 프레베리 서오릉 |
| 채석강 | 채석강리조트 |
| 화순 고인돌 유적 | 화순고인돌전통시장 |
| 함평 한우 | 함평천지전통시장 |
| 의령 망개떡 | 의령전통시장 |
| 양주 별산대놀이 | 양주문화원 |
| 외암마을 | 아산외암마을야행 |
| 운문사 | 운문사계절 캠핑장 |
| 상생의 손 | 호미곶 고래마을 카라반펜션 |

**서버 seed는 `caption`에 원래 이름만 옮겼기 때문에 어긋남이 데이터상 보이지 않았다.**
행만 보면 "성산일출봉 / 어떤 URL"이라 정상으로 읽힌다.

바람의 언덕·덕유산국립공원 2건은 `title`이 맞는데도 사진이 부정확했다 — 업스트림
이미지 자체의 문제다.

## 서버 조치 (V79 직접 수정)

V79는 이 슬라이스의 미병합 마이그레이션이라 파일을 직접 고쳤다.

- **13건 교체** — TourAPI에서 올바른 `contentid`를 다시 찾아 이미지를 받았다.
  교체본은 다시 전량 육안 검증했고, 그 과정에서 2건(바람의 언덕·채석강)이 반려되어
  갤러리에서 다른 사진으로 골랐다.
- **4건 삭제** — 함평 한우·의령 망개떡(특산품이라 TourAPI에 이미지 없음),
  운문사·동피랑 벽화마을(사찰/마을 자체 이미지 없음).
- **순번 재부여** — 삭제로 `display_order` 0이 빈 칸이 생기므로 당겨 메웠다.
  결과적으로 161칸 전부가 대표 이미지를 갖는다(371건).

로컬 DB 복구는 `problem/SPEC-0030-repair-local-db.sql` 참고.

## planner에 필요한 조치 (미착수)

**이름 검색의 첫 결과를 그대로 쓰지 않아야 한다.** 여기서 고쳐도 원본이 그대로면
특산품 14건을 추가할 때 같은 일이 반복된다. 검증 실마리는 이미 데이터에 있다:

- `name_ko`와 `tour.title`이 다른 항목이 224건이고, 대부분은 정상이다
  ("부산광안대교", "경주 첨성대" 같은 접두어 차이).
- 그중 **업종어가 붙은 것**(밀면·짜장·리조트·펜션·캠핑장·전통시장·점)은 기계적으로
  걸러낼 수 있다.

가장 확실한 것은 이름 대신 **좌표로 조회**하는 것이다. 161칸은 이미 경계를 갖고 있다.
