## 설계

> **2026-09-30 범위 확장.** 아래 절(경계 불변·판정 분류·영속성 영향 없음)은 확장 전 설계다. 경계·영속성·서비스 모양은 D-32~D-44가 대체하며, context별 애그리거트 경계는 S12~S15 착수 시 합의해 이 문서에 추가한다.

**도메인 / 애그리게이트 경계.** 경계는 바꾸지 않는다(D-04). 바뀌는 것은 규칙의 자리다. 대표 사례:
